# This file no longer lists the members-only or admin pages, and that is the
# point. `Disallow` does not hide a path — it publishes it. Anyone can read
# robots.txt, and the log analysis showed exactly that: someone fetched it and
# went straight to the admin page it named.
#
# Those pages never needed a crawler directive. They render nothing without a
# token, so there was no index risk to prevent; the directive was the only
# thing telling anyone they existed.
#
# What replaces it is `<meta name="robots" content="noindex, nofollow">` on the
# pages themselves. That is also the mechanism that actually works: a crawler
# blocked by `Disallow` cannot fetch the page, so it can never see a noindex —
# the two directives were working against each other. The meta tag is on every
# page this file used to name.
#
# Note the `$` anchor: the PUBLIC page is /course-details (with the s) and must
# stay crawlable; /course-detail is the member player and carries a noindex.
